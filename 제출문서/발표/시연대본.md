# 한빛 WMS Lite · 10분 발표·시연 대본

- 발표 자료: `발표/발표자료.html` (→ 키로 넘김, `f` 전체 화면)
- 주소: 화면 https://hanbit-wms-web.onrender.com · API https://hanbit-wms-api.onrender.com · 저장소 https://github.com/hyliliana/hanbit-wms-lite
- **발표 직전에 화면 주소를 한 번 열어 무료 서버를 깨워 둡니다.** 잠든 상태면 첫 접속이 50초쯤 늦습니다. API 주소도 한 번 엽니다.
- 시연 전 준비: 파손 보고에 사진이 필수입니다. `발표/시연자료/시연용_파손사진.jpg`를 시연 기기에서 바로 고를 수 있게 둡니다.
- 시연 전 준비: 배포 주소 탭 3개를 미리 엽니다. ① 관리자 PC 화면 ② 작업자 화면(브라우저 휴대폰 폭) ③ 화주사 화면(FRESH 담당자). 젖은 박스 사진 1장과 `FROZEN_취급지침서_v2.md`를 바탕화면에 둡니다.
- 시연 데이터: "2시간 반 전 보고·미확인" FRESH 우유 파손 1건이 미리 들어 있습니다. 리허설에서 확인 처리했다면 발표 전에 데이터를 처음 상태로 되돌립니다.
- 시간을 지키는 원칙: 시연 4분을 넘기면 2:40 개정 단계를 화면 캡처 설명으로 대체합니다.
