## 1. 고객 현황

| 항목 | 내용 |
|---|---|
| 하는 일 | 화주사(물건 주인 회사) **18곳**의 물건을 맡아 보관·출고 |
| 사람 | 센터장 1명, 관리자 4명, 작업자 30명 |
| 구역 | 상온, 냉장, 냉동. 화주사마다 쓰는 구역이 다르고, 한 화주사가 여러 구역을 쓰기도 함 (최 과장) |
| 지금 일하는 방식 | 입고·출고는 화주사 **엑셀**로 받음, 작업자는 **종이 작업지시서**, 파손은 **관리자 단체방**에 사진 |
| 고객이 가진 자료 | 화주사별 취급 지침서(18곳, 약 500쪽, 일부 개정판), 보관 계약서(18건, 약 200쪽), 입출고·재고 엑셀(약 6,000행), 구역별 보관료 단가(엑셀) |

**장면:** 월요일 오전, 냉장 구역 작업자 장 씨가 젖은 박스를 발견해 단체방에 사진을 올림 → 관리자는 출고 중이라 **1시간 뒤** 확인 → 최 과장이 그 화주사 지침서에서 "파손 입고 시 처리 방법"을 찾음. 화주사마다 반송/사진만 보내고 보관 등 처리법이 다름.

## 3. 진짜 문제

겉으로 보이는 요청은 여러 개지만 뿌리는 하나입니다. **화주사 18곳의 서로 다른 규칙이 사람 머리와 종이·단체방에만 있어서, 현장에서 그 규칙을 제때 찾지도 지키지도 못합니다.** 인터뷰에서 확인한 가장 최근 사고도 이것입니다. 파손 박스 처리 방법을 찾는 동안 **작업이 1시간 멈췄습니다** (센터장·장 씨).

| 현상 | 원인 | 영향 |
|---|---|---|
| 파손 사진이 단체방에 묻혀 관리자가 1시간 뒤에 봄 (기준은 30분) | 보고 통로가 정해져 있지 않음, 시간대·구역별 담당이 없음, 확인 여부가 기록되지 않음 | 작업 중단, 확인 지연 |
| 확인 후에도 지침서를 찾느라 다시 늦어짐 | 지침서 18종·10~80쪽, 외울 수 없음 | 처리가 두 번 늦어짐, 화주사별 처리를 틀리게 할 위험 |
| 책임(우리/운송사) 판단 근거를 나중에 찾기 어려움 | 사진·보고가 단체방에만 남음 | 화주사·운송사와 책임 다툼 시 근거 부족 |
| 지침서가 바뀌어도 어디가 바뀌었는지 모름 | 개정판 비교 수단 없음, 작업자에게 전달 안 됨 | 예전 방식대로 처리할 위험 |
| 예정·실제 입고 수량 차이를 따로 기록·통보 | 엑셀과 종이 작업지시서가 따로 놂 | 재고 불일치, 화주사 통보 누락 |
| 화주사 문의 전화 (재고·입고·출고) | 화주사가 볼 화면이 없음 | 관리자 시간 소모. 단, 다른 화주사 물건·계약 내용은 절대 보이면 안 됨 |

| 10 | 외국인 작업자 | 헷갈리는 것, 사용 언어 | 작업 순서·주의할 점, 특히 화주사별 처리 방법. 언어는 "정확히 말씀드리기 어렵네요" (장 씨) | 절반 | RQ-15 미룸. 사용 언어 **미확인 → 고객 확인 필요** |

### "정해진 기준이 없다"는 답의 처리 원칙

고객이 기준이 없다고 답한 것은 **시스템이 대신 정하면 안 되는 부분**입니다. 사람(센터장·관리자·화주사)의 판단으로 남겨 둡니다.

| 기준 없음 | 출처 | 시스템이 하는 것 | 하지 않는 것 |
|---|---|---|---|
| 지침서와 계약서가 다를 때 우선순위 | 최 과장 (Q9), 센터장 (2-9: "화주사와 확인해서 정하는 게 맞습니다") | 두 내용을 **나란히** 근거와 함께 보여 주고 "화주사와 확인 필요" 경고, 확인 결과를 기록 | 어느 쪽이 맞다고 답하기 |
| 기한이 없는 화주사의 통보 기한 | 최 과장 (2-4: "기본 기한은 따로 정해 둔 게 없어요") | 지침서에 기한이 있으면 그 기한을 근거와 함께 보여 줌. 통보 사실·시각 기록 | 기본 기한을 만들어 초과 판정 |
| 시간대·구역별 파손 담당 | 관리자 김 (Q3) | 모든 관리자에게 보이고, 확인한 사람을 기록. 30분 초과 시 센터장에게 알림 | 담당자 자동 배정 |
| 화주사 공개: 보관 위치·처리 메모 | 최 과장 (2-5: "아직 정해 두지 않았습니다") | 비공개로 둠 | 결정 전에 공개 |
| 책임 판단에 운송장·차량번호·기사 확인이 필요한지 | 센터장 (2-3: "지금 정해 둔 목록은 없어요") | 필수 3항목(사진·발견 시각·입고 물건)만 받음 | 항목을 임의로 필수화 |
| 우리/운송사 책임 판단 | 센터장 (Q5) | 사진·보고·확인 기록을 한곳에 보관 | 책임 판정 |
