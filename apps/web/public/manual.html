1. 한 장 요약

한빛 WMS Lite는 화주사마다 다른 입고·파손·보관 규칙을 현장에서 바로 찾고, 지키고, 기록하도록 돕는 앱입니다. 이번에 센터에서 달라지는 점은 아래 여섯 가지입니다.

1
화주사 규칙을 휴대폰으로 바로 찾습니다.

질문하면 그 화주사의 현행 지침서·계약서에서 답을 찾고, 근거 조항(문서명 · 판 · 조항명)을 함께 보여 줍니다.

2
파손은 사진과 함께 바로 보고되고, 30분 넘게 확인이 없으면 알림이 뜹니다.

사진과 입고 물건이 있어야 보고할 수 있습니다. 발견 시각은 보고 누른 순간 자동으로 기록됩니다. 30분을 넘긴 미확인 건은 센터장 화면 맨 위에 빨간 알림으로 표시됩니다.

3
화주사 통보 기한을 자동으로 계산합니다.

지침서의 파손 조항에 적힌 "N시간 안" 또는 "당일 안"을 읽어 통보 마감 시각을 보여 줍니다. 지침서에 기한이 없으면 임의로 정하지 않고 "관리자 판단"으로 표시합니다.

4
지침서가 바뀌면 바뀐 조항만 알려 주고, 작업자가 '읽었습니다'로 확인합니다.

새 판을 올리면 추가·변경·삭제된 조항을 보여 줍니다. 작업자는 판마다 한 번만 확인하면 됩니다.

5
지침서에 없는 질문은 사람을 거쳐 답합니다.

작업자 → 관리자 → (필요하면) 화주사 순서로 묻고, 답은 다시 관리자를 거쳐 작업자에게 전달됩니다. 저장된 답은 같은 질문이 올 때 '센터 답변'으로 다시 나옵니다.

6
화주사는 자기 회사 물건만 봅니다.

자기 회사의 재고·입고 내역·파손 보고를 볼 수 있고, 센터가 보낸 문의에 답할 수 있습니다. 보관 위치, 작업자 이름, 센터 메모, 계약 내용은 보이지 않습니다.

꼭 기억해 주세요 AI가 찾아 준 답은 참고용입니다. 항상 아래 근거 조항 원문을 확인하세요. 파손 책임과 최종 처리는 관리자·센터장이 판단합니다. 시스템은 화주사에 자동으로 연락하지 않습니다.

3. 역할별 사용법

아래 번호 순서대로 따라 하시면 됩니다. 버튼과 탭의 이름은 화면에 적힌 그대로 적었습니다.

📱 작업자 (휴대폰)

하는 일: 내 입고 작업 확인과 완료, 파손 보고, 화주사 규칙 질문, 지침서 개정 확인.

탭 이름무엇을 하나요
내 작업오늘 할 입고 작업, 개정 알림, 완료한 작업
파손 보고파손을 사진과 함께 관리자에게 보고
규칙 질문화주사 규칙을 질문하고 근거 조항 확인
내 질문관리자에게 보낸 질문의 답 확인

A. 오늘 할 일 확인하기 (탭: 내 작업)

  1. 휴대폰으로 접속 주소를 열고 로그인합니다.
  2. 맨 위 탭 내 작업 N에서 남은 입고 작업을 봅니다. 카드에는 화주사, 품목, 로트 번호, 보관 위치, 예정 수량, 유통기한이 있습니다.
  3. 카드 맨 위에 노란 알림 상자(📢 "○○ 지침서 제N판으로 바뀌었습니다")가 있으면 내용을 읽고 읽었습니다를 누릅니다. 한 번 누르면 "읽음 확인 시각"이 표시되고, 같은 판은 다시 누를 필요가 없습니다.
  4. 작업 카드의 ○○ 입고 주의사항 보기를 누르면 그 화주사 현행 지침서의 입고·검수·수량·온도·파손 조항 원문이 펼쳐집니다. 닫을 때는 주의사항 닫기를 누릅니다.

B. 입고 완료하기 (탭: 내 작업)

  1. 작업 카드의 실제 받은 수량 칸(안내 문구: 세어 본 수량)에 실제로 센 숫자를 입력합니다. 0개면 0을 입력합니다.
  2. 입고 완료를 누릅니다.
  3. 화면 메시지를 확인합니다.
    • "수량 일치"라고 나오면 그대로 끝입니다.
    • "예정과 +N개 차이 → 관리자에게 표시됩니다"라고 나와도 센 숫자를 고치지 마세요. 차이는 관리자 화면에 자동으로 표시됩니다.
  4. 끝난 작업은 아래 완료한 작업 목록에 최근 5건까지 보입니다.

실제 수량을 넣지 않으면 완료되지 않습니다.

C. 파손 보고하기 (탭: 파손 보고, 또는 작업 카드의 파손 있음)

  1. 파손된 물건이 있는 작업 카드에서 파손 있음을 누릅니다. 그러면 그 입고 건(품목·로트·위치·예정 수량)이 자동으로 연결됩니다. 탭 파손 보고에서 직접 고를 수도 있습니다.
  2. 화주사를 고릅니다. (연결된 건이면 자동으로 맞춰집니다.)
  3. 입고 물건 (필수)에서 품목을 고릅니다. 연결된 건이면 이미 정해져 있습니다.
  4. 박스 라벨/송장 번호 (선택)이 있으면 적습니다.
  5. 파손 수량 (박스)에 몇 박스인지 적습니다. 기본값은 1입니다.
  6. 어떤 파손인가요에 상황을 적습니다. 예: "박스 한쪽이 젖어 있고 바닥이 눌렸음"
  7. 사진 (필수)에서 사진을 찍거나 고릅니다. 사진은 자동으로 작게 줄어서 저장됩니다.
  8. 관리자에게 바로 보고를 누릅니다. 화주사, 물건, 설명, 사진이 모두 있어야 버튼이 켜집니다. 누르면 "보내는 중... (지침 찾는 중)"이 잠깐 나옵니다.
  9. 보고가 끝나면 그 화주사의 파손 처리 방법(근거 조항 포함)과 화주사 통보 마감 시각·남은 시간이 나옵니다. 읽고 확인을 누릅니다.
발견 시각은 자동으로 기록됩니다 따로 입력하지 않아도 보고를 누른 시각이 발견 시각으로 저장됩니다. 최종 처리는 관리자가 확인한 뒤에 정해집니다.

D. 규칙 질문하기 (탭: 규칙 질문)

  1. 화주사를 고릅니다. 화주사를 고르기 전에는 질문을 보낼 수 없습니다.
  2. 자주 찾는 질문 버튼(파손된 박스가 입고되면 어떻게 처리하나요 / 보관 온도 범위 / 출고 순서) 중 하나를 누르거나, 질문 칸에 상황을 적습니다. 예: "박스가 젖은 채로 입고됐어요. 어떻게 해야 하나요?"
  3. 질문하기를 누릅니다. 잠시 뒤 답이 나옵니다.
  4. 답 아래의 [1] [2] 근거를 꼭 확인합니다. 근거에는 문서 이름, 제N판, 조항명과 원문이 함께 있습니다.
  5. 센터 답변이 있으면 "센터 답변" 표시와 함께 확인 날짜가 나옵니다. 지침 개정 후 재확인 필요 표시가 있으면 관리자에게 먼저 확인하세요.
  6. 근거를 찾지 못했다고 나오면 관리자에게 확인 요청을 누릅니다. 보낸 뒤에는 "관리자에게 확인 요청을 보냈습니다"가 나옵니다.

E. 내 질문 확인하기 (탭: 내 질문)

  1. 보낸 질문마다 상태가 보입니다. 관리자 확인 중 → 답변 완료
  2. 답변이 완료되면 답과 출처(관리자 답변, 또는 화주사 확인 날짜)가 보입니다.
  3. 화면은 10초마다 자동으로 새로 고쳐집니다.

작업자 화면에는 화주사와 주고받은 내용은 보이지 않습니다. 최종 답만 보입니다.

💻 관리자 (PC)

하는 일: 파손 확인과 화주사 통보 기록, 입고 등록과 수량 차이 확인, 재고 확인, 지침서·계약서 새 판 올리기, 질문 처리.

탭에 빨간 숫자 배지가 붙으면 처리할 건이 있다는 뜻입니다.

A. 요약 보기 (탭: 요약)

  1. 로그인하면 요약이 먼저 열립니다. 카드 다섯 개를 봅니다: N분 넘게 확인 안 된 파손, 화주사 통보 기한 지난 파손, 미확인 파손 보고, 수량 차이 입고, 대기 중 입고 작업.
  2. 화면 위쪽에 빨간 띠가 뜨면 30분을 넘긴 미확인 파손이 있다는 뜻입니다. 띠를 누르면 파손함으로 바로 이동합니다.
  3. 숫자 카드를 누르면 해당 탭으로 이동합니다. 화면은 10초마다 새로 고쳐집니다.

B. 파손 확인하고 화주사 통보 기록하기 (탭: 파손함)

  1. 미확인 건은 빨간 테두리로 보입니다. 보고 후 N분 칩이 30분을 넘으면 빨간색으로 바뀝니다.
  2. 사진, 설명, 입고 물건, 작업 카드 정보(로트·위치·예정 수량)를 확인합니다.
  3. 지침서 기준 처리 방법 (AI가 찾은 근거)과 근거 조항을 읽습니다.
  4. 화주사 통보 마감 시각과 남은 시간을 확인합니다. "기한 없음 · 관리자 판단"이면 계약과 지침서를 보고 관리자가 직접 정합니다.
  5. 처리 메모 칸(예: "격리 칸 이동, 화주사 통보 완료")에 처리 내용을 적습니다.
  6. 이미 화주사에 알렸다면 화주사에 통보함을 체크합니다.
  7. 확인 처리를 누릅니다. 확인 처리는 한 번만 할 수 있습니다.
  8. 통보를 아직 하지 않았다면, 확인 뒤에 해당 건에서 화주사 통보 완료 기록을 눌러 나중에 기록할 수 있습니다.
시스템이 하지 않는 일 화주사에 연락하거나, 격리·반송 같은 실제 처리를 실행하지 않습니다. 실제 통보와 처리는 사람이 하고, 그 내용을 메모와 통보 기록으로 남깁니다.

C. 입고 등록과 수량 차이 확인 (탭: 입고·수량 차이)

  1. 입고 예정을 만들려면 화주사 → 품목 → 예정 수량 → 보관 위치(예: C-01-04) 순서로 고릅니다. 유통기한은 있을 때만 적습니다.
  2. 작업지시 만들기를 누릅니다. 예정 수량은 1 이상의 정수, 보관 위치는 필수입니다.
  3. 만든 작업은 작업자의 내 작업에 나타납니다. 특정 작업자를 지정하는 화면은 아직 없고, 먼저 완료한 작업자에게 배정됩니다.
  4. 아래 입고 내역 표에서 예정·실제·차이를 봅니다. 차이가 있는 행은 빨갛게 표시됩니다.
  5. 차이 건만 보려면 수량 차이만을 체크합니다.

D. 재고 보기 (탭: 재고)

  1. 상단 선택 칸에서 전체 화주사 또는 특정 화주사를 고릅니다.
  2. 품목, 구역(상온·냉장·냉동), 위치, 로트 번호, 수량, 입고일, 유통기한을 봅니다. 유통기한이 가까운 순으로 나옵니다.

E. 지침서·계약서 새 판 올리기와 바뀐 조항 보기 (탭: 지침서·계약서)

  1. 화주사와 종류(취급 지침서 / 보관 계약서)를 고릅니다.
  2. 파일에서 텍스트 파일(.md 또는 .txt)을 고릅니다. PDF는 올릴 수 없으니 텍스트로 바꾼 뒤 올리세요.
  3. 파일 이름과 글자 수가 보이면 올리고 비교하기를 누릅니다. "분석 중..."이 잠시 나옵니다.
  4. 결과 화면에서 제N판 → 제M판 · 변경 · 추가 · 삭제 개수, 요약, 조항별 전·후 원문을 확인합니다.
  5. 새 판이 현행이 되고 예전 판은 보관으로 남습니다.
  6. 아래 문서 목록에서 보기를 누르면 작업자 읽음 확인 N/전체명과 작업자별 확인 시각을 볼 수 있습니다. 끝나면 닫기.
파일 형식 주의 조항은 반드시 ## 제N조 (조항명) 형식이어야 합니다. 이 형식이 없으면 "조항 형식을 찾지 못했습니다"라며 올라가지 않습니다.

F. 질문함 처리하기 (탭: 질문함)

질문 카드에 보이는 상태: 새 질문 화주사 답 대기 화주사 답 도착 전달 완료

  1. 작업자가 보낸 질문 카드를 읽습니다. 새 질문은 빨간 테두리로 보입니다.
  2. 질문에 안전·보관·계약과 관련된 말이 있으면 화주사 확인 필요 체크가 자동으로 켜집니다. 필요하면 직접 켜거나 끌 수 있습니다.
  3. 처리 방법을 고릅니다.
    • 바로 답변: 관리자 판단으로 답을 적고 바로 답변을 누르면 작업자에게 바로 전달됩니다. 화주사 확인이 필요한 질문이면 화면에서 먼저 화주사 확인을 권합니다.
    • 화주사에 문의: 화주사에 보낼 문장을 다듬고 화주사에 문의를 누릅니다. 화주사에는 문의 내용만 가고 작업자 이름은 가지 않습니다.
    • 외부 확인 기록: 전화나 메일로 화주사에 직접 확인했을 때 씁니다. 확인 방법(전화·메일·메신저·방문), 확인 날짜, 화주사가 알려 준 내용을 적고 외부 확인 기록을 누릅니다.
  4. 화주사 답이 도착하면 카드에 화주사 답 도착이 붙습니다. 답을 확인하고 다듬은 뒤 작업자에게 전달을 누릅니다.
  5. 전달이 끝나면 센터 답변으로 저장을 누릅니다. 저장된 답은 같은 화주사에 같은 질문이 올 때 작업자의 규칙 질문 화면에 "센터 답변"으로 나옵니다.
  6. 화면 아래 저장된 센터 답변에서 지침 개정 후 재확인 필요 표시가 붙은 답은 내용을 확인한 뒤 재확인 완료를 누릅니다.

G. 규칙 질문 (탭: 규칙 질문)

작업자의 규칙 질문과 같은 방식입니다. 근거가 없으면 관리자에게 확인 요청이 나오는데, 관리자가 누르면 그 질문이 바로 질문함에 들어갑니다.

💻 센터장 (PC)

센터장 계정은 관리자와 같은 화면과 같은 기능을 씁니다. 다른 점은 맨 위 알림 문구뿐입니다. 센터장은 아래 흐름에 집중하면 됩니다.

센터장이 주로 보는 것

  1. 요약의 맨 위 빨간 띠를 확인합니다. 센터장에게는 "🔔 센터장 알림: N분 넘게 확인 안 된 파손 N건 — 관리자 확인이 늦어지고 있습니다"로 표시됩니다.
  2. 띠를 누르면 파손함으로 이동합니다. 아직 확인되지 않은 건을 관리자와 함께 확인합니다.
  3. 화주사 통보 기한 지난 파손 카드를 확인합니다. 기한을 넘긴 통보는 계약서상 늘어난 손해를 센터가 부담할 수 있어, 해당 건에는 붉은 경고가 표시됩니다.
  4. 지침서·계약서에서 새 판을 올린 뒤 작업자 읽음 현황을 확인합니다.
  5. 질문함에서 화주사 확인 필요 표시가 붙은 질문을 관리자와 함께 봅니다.
현재 화면의 특징 센터장 전용으로 따로 나뉜 기능은 아직 없습니다. 센터장과 관리자는 같은 권한을 씁니다. 알림 문구만 센터장용으로 다릅니다.

💻 화주사 (PC · 휴대폰)

하는 일: 자기 회사 재고와 입고 내역 확인, 파손 보고 현황 확인, 센터가 보낸 문의에 답하기. 자기 회사 물건만 보이며, 다른 화주사 정보는 서버가 막습니다.

탭 이름무엇을 하나요볼 수 없는 것
내 재고품목, 구역, 로트, 수량, 입고일, 유통기한보관 위치
입고 내역품목, 예정 수량, 실제 수량, 차이, 완료 시각보관 위치, 작업자, 센터 메모
파손 보고파손 내용, 사진, 센터 확인 상태, 센터 통보 시각센터 메모, 확인자, 내부 처리 지침
센터 문의함센터가 보낸 문의에 답하기작업자 이름, 원래 질문

A. 재고와 입고 내역 보기

  1. 내 재고에서 자기 회사 재고를 봅니다.
  2. 입고 내역에서 예정 수량과 실제 수량을 비교합니다. 차이가 있으면 빨갛게 표시됩니다. 완료된 건은 완료 시각이, 아직 안 된 건은 입고 예정이 나옵니다.

B. 파손 보고 현황 보기 (탭: 파손 보고)

  1. 자기 회사 파손 건이 카드로 나옵니다. 카드에는 센터 확인 중 또는 센터 확인 완료 표시가 있습니다.
  2. 파손 내용과 사진을 보고, 센터가 통보한 시각이 있으면 함께 확인합니다.

화주사 화면에서는 파손을 새로 보고할 수 없고, 보기만 할 수 있습니다.

C. 센터 문의에 답하기 (탭: 센터 문의함)

  1. 센터가 보낸 문의는 답변 필요 카드로 나옵니다.
  2. 문의 내용을 읽고 센터에 보낼 답을 적어 주세요 칸에 답을 적습니다.
  3. 전송을 누릅니다. 전송하면 카드에 답변 보냄이 붙고, 센터가 확인할 수 있게 됩니다.
한 번 보낸 답은 화면에서 고칠 수 없습니다 보내기 전에 한 번 더 확인해 주세요. 수정이 필요하면 센터 담당자에게 직접 알려 주세요.

화주사 담당자는 규칙 질문과 지침서·계약서 원문을 볼 수 없습니다. 계약 내용은 화주사에 공개되지 않습니다.

5. 자주 묻는 질문

Q1. 답이 '근거 없음'으로 나오면 어떻게 하나요?

화면에 "지침서에 없는 내용이에요"라고 나옵니다. 현장에서 혼자 정하지 말고 관리자에게 확인 요청을 누르세요. 관리자 답은 작업자의 내 질문 탭에 나타납니다. 급하면 관리자에게 직접 말해서 판단을 받으세요.

Q2. 화면이 안 열리거나 멈춘 것처럼 보여요.

① 처음 여는 것이라면 1분 정도 기다리세요. 무료 서버가 깨어나는 시간입니다.
② 새로고침을 한 번 해 보세요.
③ "로그인이 만료되었습니다"가 나오면 다시 로그인하세요. 로그인은 12시간 뒤에 만료됩니다.
④ "처리 서버에 연결할 수 없습니다"가 계속 나오면 휴대폰이나 PC의 인터넷 연결을 확인한 뒤, 운영 담당자에게 알려 주세요.

Q3. 파손 사진이 꼭 필요한가요?

네, 필수입니다. 사진이 없으면 관리자에게 바로 보고 버튼이 켜지지 않고, 서버도 보고를 받지 않습니다. 사진은 보고할 때 자동으로 작게 줄어서 저장됩니다.

Q4. 30분이 지나면 관리자나 센터장에게 문자가 자동으로 가나요?

아닙니다. 지금은 화면 안의 알림만 있습니다. 요약 탭의 빨간 띠와 센터장 화면 맨 위의 알림으로 확인합니다. 문자나 푸시 알림은 아직 없습니다.

Q5. 실제 수량을 잘못 눌러서 입고 완료를 했어요.

완료한 입고의 수량을 고치는 화면은 아직 없습니다. 바로 관리자에게 알리고, 운영 담당자에게 수정을 요청하세요. 이미 완료된 작업을 다시 완료할 수는 없습니다.

Q6. 화주사 통보 기한이 "관리자 판단"이라고 나와요. 왜 그런가요?

그 화주사의 현행 지침서에서 파손 조항에 "N시간 안"이나 "당일 안"이라는 문구를 찾지 못했다는 뜻입니다. 시스템은 기한을 추측해서 넣지 않습니다. 관리자가 계약과 지침서를 확인해서 정해 주세요.

Q7. AI가 찾은 답을 그대로 믿어도 되나요?

근거 조항 원문을 꼭 읽고 확인하세요. AI는 관련 조항을 찾아 주는 도구입니다. 파손 책임 판단과 최종 처리는 사람이 합니다. 지침서와 계약서가 서로 다르면 AI가 어느 쪽이 맞는지 정하지 않고, "화주사와 확인이 필요합니다"라고 표시합니다.

6. 인수인계 (운영 담당자용)

이 장은 시스템을 맡는 운영 담당자를 위한 내용입니다. 비밀번호, 데이터베이스 주소, API 키는 이 문서에 적지 않았습니다. 서버 환경변수에서만 관리하세요.

새 지침서·계약서 등록 방법

  1. 문서를 텍스트 파일(.md 또는 .txt)로 준비합니다. PDF는 올릴 수 없습니다.
  2. 맨 위에 # 문서 제목을 적습니다. 없으면 제목은 "문서"로 표시됩니다.
  3. 조항마다 ## 제N조 (조항명)으로 시작합니다. 이 형식이 없으면 등록이 거부됩니다.
  4. 관리자 계정으로 로그인해 지침서·계약서 탭에서 화주사와 종류를 고르고 파일을 올린 뒤 올리고 비교하기를 누릅니다.
  5. 판 번호는 자동으로 하나씩 올라갑니다. 예전 판은 보관되고, 같은 화주사·같은 종류의 현행 문서는 하나만 남습니다.
  6. 결과 화면에서 바뀐 조항을 확인합니다. 작업자에게는 14일 동안 개정 알림이 뜹니다.

예시 (형식만 참고하세요):

# ○○ 취급 지침서 (제2판)

## 제1조 (적용 범위)
...

## 제5조 (파손 입고 시 처리)
... 발견 후 N시간 안에 화주사에 통보합니다 ...
... 또는 "발견 당일 안에 통보합니다" ...

조항명에 '파손'이 들어가고 본문에 "N시간 안" 또는 "당일 안"이 있으면, 파손 보고 때 통보 기한이 자동으로 계산됩니다. 문구를 바꿀 때는 이 표현을 기준으로 맞춰 주세요.

계정 추가와 변경

계정 추가, 역할 변경, 비밀번호 재설정은 화면에서 할 수 없습니다. 운영 담당자에게 요청하세요.

실운영 전에 점검할 항목 로그인 화면은 등록된 계정 목록을 그대로 보여 주고, "시연 비밀번호" 안내 문구가 고정되어 있습니다. 실제 운영 전에는 이 목록과 안내 문구를 빼거나 제한하는 것을 검토하세요.

알려진 한계

  • 무료 서버라 첫 접속이 느립니다. 쓰지 않는 시간이 지나면 서버가 잠들고, 다시 깨어나는 데 약 1분 걸릴 수 있습니다.
  • AI 답변은 반드시 근거 조항을 확인해야 합니다. 근거 조항 원문과 실제 지침서를 대조해서 쓰세요.
  • 바코드는 지원하지 않습니다. 입고 물건은 목록에서 고르고, 라벨 번호는 직접 입력합니다.
  • 엑셀 품목정보 연동은 다음 단계입니다. 지금은 품목을 데이터베이스에 직접 등록해야 합니다.
  • 지침서 업로드는 텍스트(.md/.txt)만 됩니다. PDF는 변환해서 올려야 합니다.
  • 문자나 푸시 알림은 없습니다. 30분 알림과 통보 기한은 화면에서만 확인합니다.
  • 입고 완료 후 수량을 고치는 화면은 없습니다.
  • 작업자를 지정해서 배정하는 화면은 없습니다. 미배정 작업은 먼저 완료한 작업자에게 배정됩니다.
  • 지침서와 계약서가 충돌하면 경고만 표시합니다. 화주사와 확인한 결과를 기록하는 곳은 아직 없습니다.
  • 파손 책임 판정, 출고 순서 자동 배정은 시스템이 하지 않습니다.
